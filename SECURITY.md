# Security policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** option under the repository's Security tab. Include the affected version, impact, reproduction steps, and any suggested mitigation.

Do not include private keys, SSH configuration, access tokens, real hostnames, or production process data in a report. You should receive an initial response within seven days.
